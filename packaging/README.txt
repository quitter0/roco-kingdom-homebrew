Roco Kingdom Homebrew - Windows x64 便携版
==========================================

运行方式
--------
1. 将整个文件夹解压到任意英文路径（例如 D:\Games\roco-kingdom-homebrew）。
2. 双击 roco-kingdom.exe 启动。
3. resources 文件夹必须与 roco-kingdom.exe 位于同一目录，请勿单独移动 exe。

系统要求
--------
- Windows 10 / 11（64-bit）
- 支持 OpenGL 3.3 的显卡驱动

操作
----
- W A S D        移动
- Space          跳跃
- Left Shift     冲刺（消耗体力）
- 鼠标移动/滚轮   旋转镜头 / 缩放距离
- E              交互（对话、商店、泉水等）
- B              打开 / 关闭背包
- 1 ~ 4          战斗中选择招式
- C / R          战斗中捕捉 / 逃跑
- H              战斗中打开道具菜单
- Enter          确认
- Esc            返回 / 打开菜单
- 方向键          图鉴翻页 / 导航

存档
----
存档文件位于 resources/save.dat。删除该文件即可重新开始。
